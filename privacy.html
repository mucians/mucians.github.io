개인정보처리방침 (Privacy Policy)

시행일: 2026년 9월 28일 · 대상: 더 컴파운더 비서 (The Compounder Assistant)

1. 사용하는 정보

이 도구는 사용자 본인이 Google 로그인으로 허용한 범위에서 본인의 Google 캘린더 일정과 Google 할 일(Tasks)만 읽고 추가·수정합니다. 그 밖의 Google 계정 정보는 요청하지 않습니다.

2. 저장과 전송

Google에서 받은 정보와 로그인 권한(토큰)은 사용자 본인의 컴퓨터에만 저장됩니다. 제3자에게 전송·판매·공유하지 않으며, 광고나 분석에 사용하지 않습니다.

3. Google API 데이터 사용 정책 준수

이 도구가 Google API로 받은 정보를 사용하고 다른 앱으로 옮기는 방식은 Google API Services User Data Policy (Limited Use 요건 포함)를 따릅니다.

4. 권한 철회

사용자는 언제든지 Google 계정 권한 설정에서 이 도구의 접근 권한을 취소할 수 있습니다. 취소하면 이 도구는 더 이상 Google 정보에 접근하지 못합니다.

English summary

This tool accesses only the owner's own Google Calendar events and Google Tasks, with the owner's consent. Data and tokens are stored only on the owner's own computer and are never sold, shared, or transferred to third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at https://myaccount.google.com/permissions.
